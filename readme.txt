بهینه‌ساز برش میلگرد — کسر خودکار موجودی انبار، لیست خرید با الگوریتم FFD، نقشه گرافیکی برش، چاپ لیبل، PDF، Excel، شورتکد و REST API.

== Description ==

* یک جریان کاری ساده: موجودی انبار همیشه ابتدا مصرف می‌شود و فقط کمبود در لیست خرید می‌آید.
* گروه‌بندی خودکار به تفکیک سایز × گرید (Ø12-AIII با Ø12-AII ترکیب نمی‌شود).
* الگوریتم First Fit Decreasing روی موجودی انبار سپس شاخه‌های نو (6m/12m/سفارشی).
* پشتیبانی از ضخامت تیغه (Kerf)، حداقل طول ته‌مانده قابل استفاده و یک قیمت پیش‌فرض هر تن برای پروژه.
* وزن واحد خودکار: d²/162 (kg/m).
* خروجی‌ها: وب UI گرافیکی (برش مفید=سبز، ته‌مانده=زرد، ضایعات=قرمز)، چاپ/PDF، CSV فارسی با BOM برای Excel، JSON برای یکپارچگی با VETRA OS.
* بخش انبار دائمی؛ ته‌مانده‌ها و ضایعات هر محاسبه به‌صورت خودکار به انبار پروژه افزوده می‌شوند.
* چاپ لیبل قطعات برای لیبل‌پرینتر یا هر چاپگر معمولی.
* درون‌ریزی لیست برش و انبار از Excel (کپی-پیست).
* درج در برگه‌ها با شورتکدهای `[vetra_cut_optimizer]` و `[vco]`؛ دسترسی نقش‌محور با نمونه `[vco roles="administrator,editor" project="12"]`.
* نقش اختصاصی «سرپرست کارگاه» با نامک `vco_site_supervisor` به‌صورت خودکار ساخته می‌شود؛ این نقش فقط از طریق برگه شورتکد کار می‌کند و به پیشخوان وردپرس دسترسی ندارد.

== REST API ==

`/wp-json/vco/v1/projects` (GET/POST) — `/projects/<id>` (GET/PUT/DELETE) —
`/projects/<id>/cuts|inventory|settings` (PUT) — `/projects/<id>/optimize` (POST) —
`/projects/<id>/results` (GET) — `/meta/weights` (GET)

نیازمند احراز هویت کوکی وردپرس با توانایی `manage_options`؛ در شورتکد می‌توان نقش‌ها را با نامک انگلیسی مشخص کرد. قابلیت پایه با فیلتر `vco_required_cap` قابل تغییر است.

== Installation ==

1. پوشه `vetra-cut-optimizer` را در `wp-content/plugins/` کپی کنید.
2. افزونه را فعال کنید — جداول `wp_rebar_*` خودکار ساخته می‌شوند.
3. از منوی «VETRA کات» در پیشخوان استفاده کنید.
4. برای کاربر سرپرست کارگاه، نقش «سرپرست کارگاه» را انتخاب کنید و شورتکد `[vco]` را در برگه عملیاتی قرار دهید.
